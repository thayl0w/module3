About Recipe Finder

🍳 What is Recipe Finder?

Recipe Finder is a comprehensive web application that helps you discover and explore recipes from around the world. Whether you're looking for traditional Filipino dishes, Italian pasta, or American comfort food, Recipe Finder has you covered with thousands of recipes at your fingertips.

✨ Features

  • Global Recipe Database: Access recipes from over 25 countries and regions
  • Smart Search: Search by ingredient, dish name, or cuisine type
  • Category Filtering: Browse recipes by category (Dessert, Beef, Chicken, etc.)
  • Country Filtering: Explore recipes by country or region
  • Favorites System: Save your favorite recipes for quick access
  • Voice Search: Use your microphone to search for recipes hands-free
  • Dark Mode: Comfortable viewing in any lighting condition
  • Detailed Instructions: Step-by-step cooking instructions and ingredient lists
  • Responsive Design: Works seamlessly on desktop, tablet, and mobile devices

🔧 Technology

This application is built using:

  • HTML5: Modern semantic markup
  • CSS3: Responsive design with animations
  • JavaScript (ES6+): Interactive functionality and API integration
  • TheMealDB API: Comprehensive recipe database
  • LocalStorage: Client-side data persistence
  • Web Speech API: Voice search capabilities

📝 How to Use

  1. Use the search bar to find recipes by name or ingredient
  2. Filter by category or country using the dropdown menus
  3. Click on any recipe card to view detailed instructions
  4. Save your favorites by clicking the "Save" button
  5. Access your saved recipes from the Favorites section
  6. Toggle dark mode for comfortable viewing

💡 Tips

  • Try searching for broad terms like "chicken" or "pasta" to see many options
  • Use country filters to explore regional cuisines
  • Save recipes you want to try later
  • Use voice search for hands-free recipe discovery
